# Дизайн приложения

Название Miro Full Exporter и общий стиль реализованы в главном окне, встроенной настройке подключения,
и агента, сообщениях о результате и ошибках, локальной странице настройки
и обоих экранах Web SDK. Совместимые старые лаунчеры открывают то же окно.
Новый мастер использует общие адаптеры в локальной тестовой копии; сама
экспериментальная ветка ещё требует интеграции.

По умолчанию выбран «Экспорт данных»: любая локальная папка, canonical JSON и
папка вложений. Параметры REST и полноты доступны отдельно от настроек Canvas.
«Для Obsidian» предлагает Miro Canvas, обычный Canvas и Advanced Canvas; готовый
JSON автоматически выбирает преобразование. Названия форматов переводятся в
понятные подписи, их значения остаются прежними. Экран результата позволяет
открыть папку, подготовить сохранённый JSON для Miro Canvas или открыть готовый
Canvas в Obsidian. Подготовка не запускает конвертацию автоматически.
Рекомендация Miro Canvas добровольна; команды, пакет и имена настроек сохраняют
совместимость.

Подключение занимает основную рабочую область без нового окна. Показывается
один шаг: создание, настройка или подключение. Выбор срока токена объясняется
до создания. Адреса доступны для копирования; Client ID и Client secret всегда
имеют отдельные строки. Ошибки показываются внутри формы. Переходы сохраняют
введённое; успешное подключение и отмена очищают поля. Язык и тема остаются
в главной боковой панели. Локальная страница повторяет эти шаги с теми же
текстами и CSP-хешем скрипта. Секреты не попадают в кнопки копирования адресов.

Основа: фиолетовые элементы управления и спокойная тёмная навигация в духе
Obsidian, жёлтые акценты и светлый точечный холст в духе Miro. Не копируем
логотипы и не представляем приложение как официальный продукт этих компаний.

Общая палитра и оболочка локальных HTML-страниц находятся в
`miro2obsidian/ui_theme.py`. Используем именованные цвета оттуда, вместо
отдельной палитры для каждого экрана.

| Роль | Цвет | Применение |
| --- | --- | --- |
| Canvas | `#f6f5fa` | Фон приложения |
| Surface | `#ffffff` | Карточки, диалоги, формы |
| Ink | `#242137` | Основной текст |
| Muted | `#625d75` | Пояснения |
| Purple | `#6842c2` | Основное действие и ссылки |
| Yellow | `#ffdd57` | Переход в Miro и отдельные акценты |
| Rail | `#262237` | Фон навигации |

Системный шрифт (Segoe UI в Windows), основной текст 15px, межстрочный
интервал 1.65, шаг отступов 8px, скругления элементов 9px и карточек 18px.
В каждом шаге одно основное действие. Нужны текстовые подписи, заметный
клавиатурный фокус и маскировка пароля. Обзор следующих этапов не должен
выглядеть как кликабельная навигация.

При ширине менее 800px навигация располагается над содержимым. Форма должна
помещаться в окно 360px и оставаться доступной при увеличении текста до 200%.
На страницах с ключами нет внешних шрифтов, изображений, скриптов и телеметрии;
сохраняем CSP и существующую локальную обработку ключей.

Нативные виджеты используют общую палитру через `miro2obsidian/desktop_ui.py`.
Переводы — в `desktop_strings.py`, атомарное сохранение только языка и темы
интерфейса — в `ui_preferences.py`. Значения режимов для кода, названия досок,
пути, копируемые команды и экспортируемый JSON сохраняются как исходные данные.
Системные диалоги выбора файлов следуют оформлению ОС; их заголовки и подписи
типов файлов используют выбранный язык приложения.

CSS и JavaScript Web SDK генерируются из общей палитры и словаря командой
`python -m scripts.build_ui_assets`. Запускайте её после изменения общих
цветов или текстов; оба сгенерированных файла должны входить в сборку.

## Темы

По умолчанию используется светлая тема. Кнопка Obsidian dark theme включает
графитовый фон и сиреневые акценты, сохраняя жёлтый цвет Miro. Cookie
`miro2obsidian_theme` хранит только `light` или `dark` в течение года и переносит
выбор между портами локального сервера в одном браузере на одном хосте. Ключи
в неё не попадают. CSP разрешает только фиксированный скрипт темы по точному
SHA-256 хешу; внешние скрипты остаются заблокированными.

## Язык

Кнопки RU / EN переключают инструкции, подписи и статус подключения без
перезагрузки и замены полей с ключами. По умолчанию используется английский;
cookie `miro2obsidian_language` запоминает `en` или `ru` на год в одном браузере
на одном хосте, включая смену порта. Названия настроек Miro и права API
сохраняются в оригинале. Общие переводы — в `miro2obsidian/ui_strings.py`.

## Пошаговый интерфейс

Четыре последовательные страницы: сценарий, источник, сохранение, ход экспорта. Перед переходом проверяются обязательные поля. Настройка агента доступна только в режиме агента, который работает с одной доской Miro. Для существующего JSON скрываются подключение Miro и SDK. Метод экспорта, состав данных и инструкция обязательного Web SDK показаны на шаге источника по умолчанию; только REST нужно выбрать явно; настройки преобразования — в свёрнутом разделе на шаге сохранения. Возврат сохраняет ввод и блокируется во время экспорта. Язык и тема доступны на всех шагах.

В источнике «Аккаунт Miro» настройка подключения идёт первой, загрузка досок — второй, выбор доски — третьим; действия выровнены слева. Выбор заблокирован до загрузки списка; в интерфейсе со статусом подключения обновление недоступно без подключения. Дополнительные данные доски идут после этих действий. Отключение или сброс списка снова блокирует выбор.

Порядок зависимостей применяется на всех экранах: настройки Miro открываются до раскрытия полей ключей; в мастере действие браузера идёт перед копированием значений; источник SDK выбирается до показа поля файла; получение данных идёт перед скачиванием, копированием или передачей результата. Статус подключения показывает только действия своего состояния. Повторный экспорт и смена режима/источника блокируются во время запуска. Ошибки ввода располагаются над навигацией.
